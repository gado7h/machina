# Machina

> [!WARNING]
> **This project has been archived and is no longer maintained.**

Machina was my attempt at building a host-neutral IBM PC-compatible x86 emulator core in **Luau**.

The goal was to emulate a BIOS-era **80386-class** machine while keeping the emulator independent of any specific runtime, allowing it to be embedded into different hosts.

I started this project to learn how emulators work, and it ended up being one of the hardest projects I've worked on. I underestimated just how complex x86 emulation really is.

Even though I never got it to the point I wanted, I learned a lot about CPU architecture, instruction decoding, memory management, and low-level programming along the way.

I'm leaving the repository up because it represents that learning experience. Maybe I'll come back to emulator development one day, but for now, this project has reached the end of its journey.

Thanks for checking it out.
